# Ed25519
# @weight 15
# @timeout-scale 4

Signatures of RFC 8032, pure x-lang.  The vectors are the RFC's 7.1
tests, and each is also what the system openssl answers (`openssl pkey
-pubout`, `openssl pkeyutl -sign -rawin`) for the same seed and message.
A signature costs fourteen seconds pure-x and a check twice that -- one
and two scalar multiplications on an interpreter -- so the file carries
the weight of an engine build and keeps to one check; the engine's spec
checks more.  A signature can hold a NUL, so it is read by its 64 bytes.

## RFC 8032 7.1

### test 1: the public key of the first seed

```x
(do
  (import x/codec/hex)
  (import x/codec/ed25519)
  (display (Hex encode (Ed25519 public
    (Hex decode "9d61b19deffd5a60ba844af492ec2cc44449c5697b326919703bac031cae7f60")))))
```

### test 1: the signature of the empty message

```x
(do
  (import x/codec/hex)
  (import x/codec/ed25519)
  (def %ed-bref (prim-ref (lit str) (lit byte-ref)))
  (def %ed-c->i (prim-ref (lit char) (lit ->int)))
  (def %ed-hex
    (fn (_ s n)
      (Hex encode-bytes
        ((fn (self i acc) (if (< i 0) acc (self (- i 1) (pair (%ed-c->i (%ed-bref s i)) acc))))
         (- n 1) ()))))
  (display (%ed-hex (Ed25519 sign
    (Hex decode "9d61b19deffd5a60ba844af492ec2cc44449c5697b326919703bac031cae7f60") "" 0 0) 64)))
```

## verification

### test 2's signature checks; an S at the group order is refused first

A signature whose S is L itself is not canonical, and the check says so
before any arithmetic.

```x
(do
  (import x/codec/hex)
  (import x/codec/ed25519)
  (def %ed-pub (Hex decode "3d4017c3e843895a92b70aa74d1b7ebc9c982ccf2ec4968cc0cd55f12af4660c"))
  (def %ed-sig (Hex decode "92a009a9f0d4cab8720e820b5f642540a2b27b5416503f8fb3762223ebdb69da085ac1e43e15996e458f3613d0f11d8c387b2eaeb4302aeeb00d291612bb0c00"))
  (def %ed-badS (Hex decode "92a009a9f0d4cab8720e820b5f642540a2b27b5416503f8fb3762223ebdb69daedd3f55c1a631258d69cf7a2def9de1400000000000000000000000000000010"))
  (display (list (Ed25519 verify %ed-pub %ed-sig (Hex decode "72") 0 1)
                 (Ed25519 verify %ed-pub %ed-badS (Hex decode "72") 0 1))))
```
