# X25519 JIT engine

# @weight 15
# @timeout-scale 4

The compiled field engine behind `(X25519 jit!)`, built by
x/codec/x25519-jit: the multiply, add, subtract, times-121666 and swap
each one compiled function over a scratch of limbs, the RFC's ladder
driven over them from x.  It is adopted only after the maker's own
differential check against the pure-x function on the RFC's exchange;
these cases re-prove agreement through the class.  The file builds an
engine and runs the pure-x reference, so it carries the weight of both.

## the engine builds and is adopted

### jit! reports the engine active, and is idempotent

```x
(do
  (import x/codec/x25519)
  (display (list (X25519 jit!) (X25519 jit!) ((Compiled named (lit x25519)) state))))
```

### the RFC's exchange holds through the engine, both ways

```x
(do
  (import x/codec/hex)
  (import x/codec/x25519)
  (X25519 jit!)
  (def %xx-a (Hex decode "77076d0a7318a57d3c16c17251b26645df4c2f87ebc0992ab177fba51db92c2a"))
  (def %xx-b (Hex decode "5dab087e624a8a4b79e17f8b83800ee66f3bb1292618b6fd1c2f8b27ff88e0eb"))
  (display (Hex encode (X25519 base %xx-a))) (newline)
  (display (Hex encode (X25519 base %xx-b))) (newline)
  (display (list (str=? (Hex encode (X25519 scalarmult %xx-a (X25519 base %xx-b)))
                        "4a5d9d5ba4ce2de1728e3bf480350f25e07e21c947d19e3376f09b3c1e161742")
                 (str=? (Hex encode (X25519 scalarmult %xx-b (X25519 base %xx-a)))
                        "4a5d9d5ba4ce2de1728e3bf480350f25e07e21c947d19e3376f09b3c1e161742"))))
```

### the engine agrees with pure-x on a key the vectors do not cover

The pure-x side is the module's own function, read through its
environment; the key is every byte value from 0x40, so every limb of the
scalar and the coordinate carries something.

```x
(do
  (import x/codec/hex)
  (import x/codec/x25519)
  (X25519 jit!)
  (def %xx-ref (eval (lit %scalarmult) (module x/codec/x25519)))
  (def %xx-set (prim-ref (lit ptr) (lit set!)))
  (def %xx-k ((prim-ref (lit str) (lit make)) 32))
  (def %xx-p ((prim-ref (lit str) (lit ->ptr)) %xx-k))
  ((fn (self i) (unless (= i 32) (do (%xx-set %xx-p i (+ 64 (* i 5)) 1) (self (+ i 1))))) 0)
  (def %xx-u (Hex decode "8462fb3f0798f9fe2c39f3823bb41cd3effe70bb5c81735be46a143135c58454"))
  (display (str=? (Hex encode (X25519 scalarmult %xx-k %xx-u))
                  (Hex encode (%xx-ref %xx-k %xx-u)))))
```
