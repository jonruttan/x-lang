## a digest collects its own garbage (#294)

Pure-x digesting allocates ~550k objects of dispatch garbage per block,
and the periodic in-loop collect never fires for inputs under 512
bytes. Before #294 every small hash therefore leaked its full garbage
-- ~70MB of real memory per call -- and batches that hash many small
files (pin verify) accumulated gigabytes until the ASan CI runner's VM
died. The completion collect returns a digest's net heap growth to
zero; this pins it by object count, with slack for cache warming.

### a small digest leaves no net garbage

```scheme
(import x/codec/sha256)
(Sha256 hex "warm-up")
(def %c0 (Heap count))
(Sha256 hex "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef")
(write (< (- (Heap count) %c0) 100000))
```

## sha256: hex-n, the length-explicit door

`hex` bounds itself by `Str8 length`, which has strlen semantics. `hex-n`
takes the length as an argument, so it reaches input `hex` cannot measure.

### hex-n agrees with hex when the length is the string's own

```scheme
(do
  (import x/codec/sha256)
  (display (str=? (Sha256 hex-n "abc" 3) (Sha256 hex "abc"))))
```

### NULs inside: the case hex cannot reach

`"A\0B\0C"` is five bytes. `Str8 length` reports 1, so `hex` digests one
byte; `hex-n` digests the region. Built through the pointer door because
every string constructor that takes text stops at the NUL as well.

```scheme
(do
  (import x/codec/sha256)
  (def %mk (prim-ref (lit str) (lit make)))
  (def %p (prim-ref (lit str) (lit ->ptr)))
  (def %set (prim-ref (lit ptr) (lit set!)))
  (def r (%mk 5))
  (def p (%p r))
  (%set p 0 65 1) (%set p 1 0 1) (%set p 2 66 1) (%set p 3 0 1) (%set p 4 67 1)
  (display (Sha256 hex-n r 5)))
```

### binary across a block boundary

200 bytes of 0..199, so the fill and the padding path both see NULs.

```scheme
(do
  (import x/codec/sha256)
  (def %mk (prim-ref (lit str) (lit make)))
  (def %p (prim-ref (lit str) (lit ->ptr)))
  (def %set (prim-ref (lit ptr) (lit set!)))
  (def r (%mk 200))
  (def p (%p r))
  ((fn (self i) (unless (= i 200) (do (%set p i (& i 255) 1) (self (+ i 1))))) 0)
  (display (Sha256 hex-n r 200)))
```
