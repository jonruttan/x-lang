# Sha256

## sha256: FIPS 180-4 vectors

### the empty string

```scheme
(do
  (import x/codec/sha256)
  (display (Sha256 hex "")))
```

## a digest collects its own garbage (#294)

Pure-x digesting allocates ~550k objects of dispatch garbage per block,
and the periodic in-loop collect never fires for inputs under 512
bytes. Before #294 every small hash therefore leaked its full garbage
-- ~70MB of real memory per call -- and batches that hash many small
files (pin verify) accumulated gigabytes until the ASan CI runner's VM
died. The completion collect returns a digest's net heap growth to
zero; this pins it by object count, with slack for cache warming.

### a small digest leaves no net garbage

```scheme
(import x/codec/sha256)
(Sha256 hex "warm-up")
(def %c0 (Heap count))
(Sha256 hex "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef")
(write (< (- (Heap count) %c0) 100000))
```
---
    #t
