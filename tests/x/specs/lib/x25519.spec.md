# X25519
# @weight 15
# @timeout-scale 4

Diffie-Hellman on Curve25519 (RFC 7748), pure x-lang.  The vectors are
the RFC's 6.1 exchange, and each is also what the system openssl
answers (`openssl pkey -pubout`, `openssl pkeyutl -derive`) for the same
keys.  An exchange costs five seconds pure-x, so the file carries the
weight of an engine build.

## RFC 7748 6.1: Alice and Bob

### Alice's public key is her scalar times the base point

```x
(do
  (import x/codec/hex)
  (import x/codec/x25519)
  (display (Hex encode (X25519 base
    (Hex decode "77076d0a7318a57d3c16c17251b26645df4c2f87ebc0992ab177fba51db92c2a")))))
```

## the field

### bytes round-trip through the field, and the top bit is ignored

A u-coordinate loads, packs to the same bytes reduced mod p; the RFC
says the top bit of the last byte is masked before use, so 0x80 there
changes nothing.

```x
(do
  (import x/codec/hex)
  (import x/codec/x25519)
  (def %xx-fb (eval (lit %fe-frombytes) (module x/codec/x25519)))
  (def %xx-tb (eval (lit %fe-tobytes) (module x/codec/x25519)))
  (def %xx-k (Hex decode "5dab087e624a8a4b79e17f8b83800ee66f3bb1292618b6fd1c2f8b27ff88e0eb"))
  (def %xx-k2 (Hex decode "5dab087e624a8a4b79e17f8b83800ee66f3bb1292618b6fd1c2f8b27ff88e06b"))
  (display (list (str=? (Hex encode (%xx-tb (%xx-fb %xx-k))) (Hex encode %xx-k2))
                 (str=? (Hex encode (%xx-tb (%xx-fb %xx-k2))) (Hex encode %xx-k2)))))
```
