# Sha384
# @weight 4

The SHA-384 digest (FIPS 180-4): SHA-512's compression from SHA-384's
initial words, cut to six words.  The vectors are the standard's and the
padding boundaries; every digest here is also what the system
`shasum -a 384` answers.

## sha384: FIPS 180-4 vectors

### the empty string and one block

```x
(do
  (import x/codec/sha384)
  (display (Sha384 hex ""))
  (newline)
  (display (Sha384 hex "abc")))
```

## the padding's boundaries

### 111, 112 and 128 bytes

```x
(do
  (import x/codec/sha384)
  (display (Sha384 hex (Str8 pad-right 111 #\y "x")))
  (newline)
  (display (Sha384 hex (Str8 pad-right 112 #\y "x")))
  (newline)
  (display (Sha384 hex (Str8 pad-right 128 #\y "x"))))
```

## binary input

### hex-n digests past a NUL

```x
(do
  (import x/codec/sha384)
  (def %s3-set (prim-ref (lit ptr) (lit set!)))
  (def %s3-r ((prim-ref (lit str) (lit make)) 5))
  (def %s3-p ((prim-ref (lit str) (lit ->ptr)) %s3-r))
  ((fn (self i bs)
     (unless (null? bs) (do (%s3-set %s3-p i (first bs) 1) (self (+ i 1) (rest bs)))))
   0 (list 65 0 66 0 67))
  (display (Sha384 hex-n %s3-r 5)))
```
