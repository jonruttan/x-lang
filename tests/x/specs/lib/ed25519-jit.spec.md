# Ed25519 JIT engine

# @weight 15
# @timeout-scale 4

The compiled scalar multiplication behind `(Ed25519 jit!)`, built by
x/codec/ed25519-jit over x/codec/fe25519-jit's field operations: the
point in a scratch of limbs, the double-and-add driven from x.  It is
adopted only after the maker's own differential check against the
pure-x function on the base point; these cases re-prove agreement
through the class.  The file builds an engine and runs the pure-x
reference, so it carries the weight of both.

## the engine builds and is adopted

### jit! reports the engine active, and is idempotent

```x
(do
  (import x/codec/ed25519)
  (display (list (Ed25519 jit!) (Ed25519 jit!) ((Compiled named (lit ed25519)) state))))
```

### the RFC's vectors hold through the engine

```x
(do
  (import x/codec/hex)
  (import x/codec/ed25519)
  (Ed25519 jit!)
  (def %ed-s1 (Hex decode "9d61b19deffd5a60ba844af492ec2cc44449c5697b326919703bac031cae7f60"))
  (def %ed-s2 (Hex decode "4ccd089b28ff96da9db6c346ec114e0f5b8a319f35aba624da8cf6ed4fb8a6fb"))
  (def %ed-bref (prim-ref (lit str) (lit byte-ref)))
  (def %ed-c->i (prim-ref (lit char) (lit ->int)))
  (def %ed-hex
    (fn (_ s n)
      (Hex encode-bytes
        ((fn (self i acc) (if (< i 0) acc (self (- i 1) (pair (%ed-c->i (%ed-bref s i)) acc))))
         (- n 1) ()))))
  (display (Hex encode (Ed25519 public %ed-s1))) (newline)
  (display (%ed-hex (Ed25519 sign %ed-s1 "" 0 0) 64)) (newline)
  (display (%ed-hex (Ed25519 sign %ed-s2 (Hex decode "72") 0 1) 64)))
```

### a signature the engine makes, the engine checks, and a wrong one it refuses

```x
(do
  (import x/codec/hex)
  (import x/codec/ed25519)
  (Ed25519 jit!)
  (def %ed-seed (Str8 pad-right 32 #\s ""))
  (def %ed-pub (Ed25519 public %ed-seed))
  (def %ed-msg "a message the engine signs")
  (def %ed-sig (Ed25519 sign %ed-seed %ed-msg))
  (display (list (Ed25519 verify %ed-pub %ed-sig %ed-msg)
                 (Ed25519 verify %ed-pub %ed-sig "a message the engine signs!"))))
```
